# 功能状态

状态更新于 2026-11-06。结果仅适用于魅族 21（meizu21 / SM8650）和本文档
记录的 r20 配置。

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| UniXNU 菜单 | 已验证 | 1080×2340，单入口两秒后自动启动 |
| UEFI → Darwin 22 → iOS | 已验证 | 已进入 iOS 16.5 桌面 |
| 显示 | 已验证 | 修正后的 1080×2340 面板与 Dock 高度 |
| 触控 | 已验证 | Goodix，桌面点击与滑动正常 |
| UFS | 已验证 | 保留的 native UFS 与 APFS 根卷路径 |
| 重启 | 已验证 | 诊断测试可回到 fastboot；正常版不执行诊断重启 |
| GPU 上电 | 实验性 | 已实测 CX/GX、HFI 和 CP 状态读取；不属于 r20 正常版 |
| GPU 绘制 | 未完成 | 没有可靠命令提交、渲染或 Metal |
| Wi-Fi | 未实现 | 尚未完成该机无线启动链 |
| 音频 | 未实现 | 尚未完成音频路由 |
| 蜂窝 | 未实现 | 尚未完成 modem 与 iOS 接口 |
| 日常使用 | 不适用 | 开发阶段版本，不能替代正常手机系统 |

“主机测试通过”“构建成功”不等于手机硬件功能已经验证。每项功能应以
`evidence/` 中的实机记录为准。
